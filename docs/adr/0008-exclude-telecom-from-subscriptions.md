# ADR-0008: 通信費をサブスクの対象外とし、Tier 1 の照合前に店名を正規化する

- **ステータス**: 採択
- **日付**: 2026-10-12
- **決定者**: Marin Miyazaki
- **関連 ADR**: ADR-0004（AI 分類の階層化）

## 背景（Context）

1. **通信費の扱いが中途半端だった**
   ServiceTemplate に「通信」カテゴリとして ahamo / povo / LINEMO / 楽天モバイルがあり、Tier 3 の AI プロンプトでも「通信キャリア」をサブスクの例に挙げていた。一方で他の通信事業者（MVNO 等）はテンプレートに無く、どこまでを対象にするかの基準が無かった。
2. **カード明細の店名表記が揺れる**
   カード会社の CSV では店名が半角カナ（例: 「ｱﾄﾞﾋﾞｶﾌﾞｼｷｶﾞｲｼｬ」「ﾌﾟﾛｹﾞｰﾄ」）や全角英数で出力されることがある。従来の Tier 1 は正規表現をそのまま当てていたため、テンプレートがあるサービス（Adobe 等）でも一致せず、後段の Tier 2/3 に流れていた（AI 呼び出しが増え、コストと判定の揺れが増える）。

## 検討した選択肢（Options Considered）

### 通信費

#### 選択肢 A: 通信事業者のテンプレートを網羅する
- メリット: 毎月の固定費をまとめて把握できる
- デメリット: 事業者・プランが多く保守が続く。本アプリの目的（気づかないうちに払い続けている定額課金の発見）から外れ、ダッシュボードの合計が「解約を検討すべきもの」以外で膨らむ

#### 選択肢 B: 通信費はサブスクの対象外とする — 採択
- メリット: 製品の目的に沿う。テンプレートの保守対象が減る。Tier 1 と Tier 3 の基準が揃う
- デメリット: 通信費を含めた固定費全体の把握には別の手段が必要

### 表記揺れ

#### 選択肢 A: テンプレートに半角カナ・全角英数のパターンを併記する
- メリット: 照合ロジックを変えずに済む
- デメリット: パターン数が倍以上に増え、書き漏れが起きやすい

#### 選択肢 B: 照合前に description とパターンの両方を Unicode NFKC で正規化する — 採択
- メリット: 全角カナでパターンを 1 つ書けば半角カナにも一致する。全角英数も半角英数として扱える。既存パターンの意味は変わらない
- デメリット: 正規化の計算が 1 行ごとに入る（数百行規模の CSV では無視できる）

## 決定（Decision）

- **通信費（携帯電話・格安 SIM・光回線・インターネットプロバイダの月額）はサブスクの対象外とする。** 意図して払っている固定費であり、本アプリが可視化したい「気づいたら払い続けている定額課金」とは性質が異なるため。
  - ServiceTemplate から通信カテゴリ（ahamo / povo / LINEMO / 楽天モバイル）を削除する。既存 DB からは `bin/rails db:seed` の再実行で削除される（seed 内の廃止リスト）
  - Subscription は service_name を文字列で保持し、ServiceTemplate への外部キーを持たないため、ユーザーが登録済みのサブスクは削除・変更しない（ユーザーが手動登録したものは尊重する）
  - Tier 3（AI 分類）のプロンプトでも、通信費を is_subscription: false とするよう指示する
- **Tier 1 の照合では、description とパターンの両方を NFKC 正規化し、大文字小文字を無視して照合する。**
- 複数テンプレートに一致し得る場合は id 昇順で先頭のものを採用する。汎用的なパターン（例: 「APPLE COM BILL」）は個別サービス（例: Apple Music）より後に seed する。

## 結果（Consequences）

### ポジティブ
- 半角カナの店名でも既存テンプレートで Tier 1 判定でき、AI 呼び出しが減る
- 対象範囲が明確になり、テンプレート追加の判断基準ができる

### ネガティブ・トレードオフ
- 通信費は AI が subscription と判定しない限り抽出結果に出ない。必要なユーザーは手動登録する
- 判定の優先順位が seed の並び順（id 順）に依存する

### フォローアップ作業
- 本番 DB への反映には seed の再実行が必要（`db:prepare` は既存 DB では seed を実行しない）
- 実データで一致しなかった店名が見つかったら、テンプレートのパターンを追加する
